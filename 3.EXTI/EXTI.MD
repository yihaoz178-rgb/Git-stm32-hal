# EXTI介绍
 ### 外部(拓展)中断事件控制器件（EXTI）
![alt text](photo/外部中断事件控制器框图.png)
**EXTI_RTSR**：上升沿触发选择寄存器

**EXTI_FTSR**：下降沿触发选择寄存器

**EXTI_SWIER**：软件中断事件寄存器

**EXTI_PR**：请求挂起寄存器

**EXTI_IMR**：中断屏蔽寄存器 

**EXTI_EMR**：事件屏蔽寄存器
>参考文档：数据手册-->9.2 外部中断/事件控制器(EXTI)
